# Global-Observation-AI-Agent

环球观察\_视频生产智能体



一、先确定核心理念



不要设计：❌ 一个“大机器人”

不要：一个AI负责所有事情，因为后期会非常混乱。

应该设计：多Agent协作系统，类似一个虚拟视频制作团队。

现在很多开源AI视频项目也是采用这种思路，例如：

OpenDirector采用多个专业Agent协作，从研究、脚本、分镜、配音、素材到渲染形成流水线。

OpenMontage也是把研究、脚本、素材、编辑、声音等拆成多个生产流程。

一些AI视频编辑Agent项目强调“可回退、可人工修改”的时间线，而不是一次性生成不可修改成品。

你的方向应该借鉴：AI负责80%的重复工作，人负责关键决策。

必须经过你确认。

四、每个Agent职责



Agent 1：新闻研究员

类似：

“记者”

输入：

伊朗局势变化

输出：

事件背景

关键事实

各方观点

可靠来源

风险提示



Agent 2：脚本编导Agent

负责：

你的核心内容。

输出：

60秒脚本

例如：

0-5秒

钩子：

美国航母再次进入中东，引发关注。

5-20秒

事件背景。

20-45秒

各方信息。

45-60秒

总结。

同时生成：

配音方案

例如：

声音：男声，新闻纪录片风格

语速：1.1倍，

停顿：关键数据停顿



Agent 3：分镜导演Agent

这是非常关键的。

它把文字变成：

时间轴

\+

画面需求

例如：

时间	旁白	画面

0-5秒	航母进入中东	航母视频

5-10秒	区域变化	地图动画

10-20秒	美国声明	新闻画面

这个Agent决定后面所有素材需求。



Agent 4：素材管理Agent

这就是你现在正在开发的部分。

但是升级后：它不应该只接受关键词。

应该接受：分镜表

例如：

输入：

镜头1：美国航母视频

镜头2：波斯湾地图

镜头3：五角大楼图片

输出：项目素材包

结构：

项目

├──01\_脚本

├──02\_分镜

├──03\_图片素材

│   ├──镜头01

│   ├──镜头02

│   └──镜头03

├──04\_视频素材

├──05\_音频

└──06\_工程文件



Agent 5：剪辑制作Agent

负责：

自动生成：

剪辑方案

时间轴

转场

BGM

特效

注意：

这里我建议：

第一阶段不要直接控制剪映。

原因：剪映自动化比较复杂。

更好的方式：

先生成：剪辑工程说明书

例如：

00:00-00:05

素材：

航母.mp4

效果：

推进

字幕：

美国航母再次进入中东



你人工导入剪映。

成熟后：

再研究：

剪映接口

Premiere脚本

FFmpeg自动渲染



Agent 6：声音字幕Agent

负责：

配音

输入：

脚本输出：voice.wav

字幕输出：subtitle.srt

字幕风格：

例如：

黄色重点词

白色普通字幕

关键词放大



Agent 7：审核Agent

非常重要。

发布前：

检查：

新闻真实性

是否有未经证实信息

标题

是否夸张

平台风险

是否敏感



最后：

输出：审核报告

通过/修改
